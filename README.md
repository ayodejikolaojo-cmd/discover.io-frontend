# Discover.io Frontend

Frontend for Discover.io — an AI-powered platform that helps creatives discover the best tools for their workflow.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS (optional)
- Git & GitHub

## Setup

Clone the repo:

git clone https://github.com/yourusername/discover-io-frontend.git

Install dependencies:

npm install

Run development server:

npm run dev

## Folder Structure

- components → reusable UI components
- pages → main application pages
- services → API calls
- hooks → custom React hooks
